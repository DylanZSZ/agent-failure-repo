## Summary

This collection documents 17 supported historical incidents from Claude Code and Codex, with 97 unresolved leads retained separately. Those leads may overlap and are not confirmed failures. The [incident table](incidents.csv) describes each record. [Coverage and limits](coverage.md) distinguish machine scanning from detailed review.

The task exercises replace private systems and data with synthetic local fixtures. There are 54 scripted checker records and zero fresh model attempts. These results validate correct/faulty examples against the checkers; they are not model failure rates. No comparison establishes that long context caused the historical mistakes.

Cases with a problem path have their own task, evidence summary, setup instructions and checker. Incident-only entries still need a reduction. Original transcripts, private source maps and search databases are excluded from this draft.
